# User guide

Sign in as the owner. Add a feed URL or a site URL; autodiscovery finds RSS, Atom, or JSON feeds. Organize feeds into folders, import/export OPML, read the unread/all/starred views, and search article text.

Selecting an article marks it read. Use `j`/`k` to move, `s` to star, and `m` to toggle read.

Create a named app credential in **Subscriptions & apps**:

- FreshRSS/Google Reader URL: `https://your-host/api/greader.php`
- Fever URL: `https://your-host/api/fever.php`
- Fever API key: `MD5(username:password)`

Copy the password immediately; it is not shown again. Revoke a credential to disconnect only that app.
